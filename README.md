# \## 📝 Write-Up Methodology

# 

# I try to follow a consistent methodology when documenting challenges.

# 

# \### 1. Overview

# Basic information about the target, platform, and difficulty.

# 

# \### 2. Reconnaissance

# Initial information gathering and attack-surface discovery.

# 

# \### 3. Enumeration

# Identifying:

# \* Open ports

# \* Services

# \* Technologies

# \* Directories and files

# \* Subdomains

# \* Application functionality

# 

# \### 4. Vulnerability Identification

# Understanding the vulnerability, how it works, and why it exists.

# 

# \### 5. Exploitation

# Documenting the exploitation process, including relevant commands and payloads.

# 

# \### 6. Impact

# Explaining what an attacker could achieve by exploiting the vulnerability.

# 

# \### 7. Remediation

# Documenting possible fixes and security recommendations.

# 

# \### 8. Key Takeaways

# Important lessons learned from the challenge.
